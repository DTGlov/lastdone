# LastDone

Remember the things life doesn’t schedule.

LastDone is an offline-first Flutter app for tracking recurring parts of everyday life.

This project uses FVM with Flutter 3.47.2.

On first launch, LastDone guides users through choosing life areas and starter trackers. Returning users go directly to Today.

Today now shows onboarding-created trackers in due-aware Needs attention, Coming up, and Recently done sections.
